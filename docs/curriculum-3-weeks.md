# 3주 커리큘럼

이 커리큘럼은 날짜 기준이 아니라 **주차별 학습 항목**으로 구성됩니다. 각 주차는 별도 폴더에 들어 있으므로, 순서대로 열어 보며 학습하면 됩니다. 실제 개발 작업 순서와 주차별 산출물은 [`3주 개발 진행 방식`](3-week-development-workflow.md)을 함께 참고하세요.

## 주차별 학습 폴더

| 주차 | 폴더 | 항목 수 | 핵심 목표 |
| --- | --- | ---: | --- |
| 1주 차 | [`docs/week-1-foundation/`](week-1-foundation/) | 5개 | 실행 환경, 안전 범위, 타입/데이터, 마켓 엔진, 단위 테스트 |
| 2주 차 | [`docs/week-2-market-flow/`](week-2-market-flow/) | 6개 | 홈/상세, 거래 패널, 포트폴리오, localStorage, 모의 정산 |
| 3주 차 | [`docs/week-3-polish-deploy/`](week-3-polish-deploy/) | 6개 | 목업 지갑, 학습 문서, E2E, 배포, 포트폴리오 |

## 1주 차 — 기초와 메커니즘

자세한 내용: [`docs/week-1-foundation/`](week-1-foundation/)

1. 프로젝트 실행 환경 준비
2. 안전 범위 이해
3. 마켓 데이터 구조 읽기
4. 마켓 엔진 이해 또는 구현
5. 단위 테스트로 메커니즘 보호

종료 기준:

- `npm run lint`와 `npm run test`가 통과합니다.
- YES를 사면 왜 YES 확률이 바뀌는지 설명할 수 있습니다.
- 이 앱이 왜 실제 거래소가 아닌지 설명할 수 있습니다.

## 2주 차 — 제품 흐름

자세한 내용: [`docs/week-2-market-flow/`](week-2-market-flow/)

1. 홈 마켓 목록 구성
2. 마켓 카드와 상세 이동 이해
3. 마켓 상세 페이지 연결
4. 거래 패널 사용 흐름 구현/이해
5. 포트폴리오와 localStorage 상태 이해
6. 모의 정산 흐름 확인

종료 기준:

- `npm run lint`, `npm run test`, `npm run build`가 통과합니다.
- 마켓 보기 → YES/NO 선택 → 포지션/확률 업데이트 → 모의 정산 흐름을 완료할 수 있습니다.
- 클라이언트 전용 상태와 순수 도메인 로직이 어디 있는지 짚을 수 있습니다.

## 3주 차 — QA, 배포, 포트폴리오

자세한 내용: [`docs/week-3-polish-deploy/`](week-3-polish-deploy/)

1. 목업 지갑 실험 이해
2. 학습 콜아웃과 설명 문구 점검
3. E2E 테스트로 핵심 흐름 보호
4. 초보자 문서 정리
5. 배포 준비
6. 포트폴리오 설명 작성

종료 기준:

- `npm run lint`, `npm run test`, `npm run build`, `npm run test:e2e`가 통과하거나 정확한 미해결 사유가 문서화됩니다.
- 안전 경계와 목업 지갑이 기본값인 이유를 설명할 수 있습니다.
- 배포 또는 포트폴리오 공유에 필요한 증거가 준비됩니다.
